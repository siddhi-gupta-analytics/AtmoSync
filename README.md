# AtmoSync – Micro-Climate Arbitrage Analytics

## Project Overview
AtmoSync is a data analytics project focused on monitoring cold-chain conditions and analyzing avocado market prices. The project combines simulated sensor data, commodity inventory information, market price observations, and transport route records to support data-driven decision-making.

## Objectives
- Monitor temperature, humidity, and vibration across containers.
- Analyze sensor readings and identify environmental variations.
- Track avocado commodity inventory.
- Analyze reported market price trends.
- Present insights through an interactive Power BI dashboard.

## Tools & Technologies
- Microsoft Excel – Data cleaning and preparation
- MySQL – Data storage and SQL analysis
- Microsoft Power BI – Interactive dashboard and visualization
- GitHub – Project collaboration and version control

## Dataset Overview
- **Sensor_Data:** 1,000 simulated readings across 5 containers.
- **Commodity_Data:** 3 avocado lots with a total quantity of 2,300 kg.
- **Market_Prices:** 9 reported price observations from Gaddiannaram APMC, Telangana.
- **Transport_Routes:** 3 route records with incomplete distance and cost information.

## Key Observations
- The sensor dataset contains 1,000 simulated readings across 5 containers.
- Total avocado inventory is 2,300 kg across 3 lots.
- The latest reported market price in the dataset is ₹175/kg.
- Market price analysis is based on 9 observations from one APMC market.
- Transport route distance and estimated cost information is incomplete.

## Team Contributions
This project was completed collaboratively by a team of four members, with responsibilities distributed across data collection, data cleaning and SQL, analysis and insights, and dashboard development.

## Important Notes
- Sensor readings are simulated and do not represent actual physical sensor measurements.
- Market price analysis is limited to the available 9 observations from Gaddiannaram APMC.
- Transport route distance and cost details are pending.
